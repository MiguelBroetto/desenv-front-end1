# Desenvolvimento Front-End I

## Sobre a disciplina

Este repositório reúne atividades práticas e exercícios desenvolvidos na disciplina de **Desenvolvimento Front-End I**.

O objetivo é aplicar os conceitos estudados em aula, desenvolver habilidades de programação para a web e registrar a evolução do aprendizado ao longo da disciplina.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo das páginas web.
- **CSS3:** estilização e apresentação visual das páginas.
- **JavaScript:** lógica de programação e recursos de interatividade.

## Objetivos de aprendizagem

- Compreender os fundamentos do desenvolvimento front-end.
- Praticar a criação e a estruturação de páginas web.
- Aplicar estilos utilizando CSS.
- Desenvolver a lógica de programação com JavaScript.
- Utilizar o GitHub para armazenar e organizar as atividades acadêmicas.
